# 🚀 JavaScript Learning Hub (Day 10 Project Submission)

A comprehensive, interactive JavaScript learning web application inspired by **GeeksforGeeks**, **W3Schools**, and **MDN Web Docs**, built with **HTML5**, **Tailwind CSS**, and modern **ES6+ JavaScript**.

---

## 📌 Project Overview
- **Project Name:** JS MasterHub
- **Category:** Educational Web App / Learning Portal
- **Tech Stack:** HTML5, Tailwind CSS, Vanilla JavaScript (ES6+), LocalStorage API
- **Content:** 10 Essential JavaScript Core Topics + 10 Practical Logical Programming Challenges with Live Interactive Code Runners.

---

## 📚 1. Core JavaScript Topics (10 Topics)

1. **Variables & Data Types:** `var`, `let`, `const`, 7 Primitive Types vs Reference Types, Memory allocation.
2. **Operators & Expressions:** Arithmetic, Strict Equality (`===`), Logical (`&&`, `||`), Nullish Coalescing (`??`), Ternary.
3. **Conditionals & Control Flow:** `if-else`, `switch-case`, Truthy vs Falsy value evaluations.
4. **Loops & Iteration:** `for`, `while`, `do-while`, `for...of` (iterables), and `for...in` (object keys).
5. **Functions & Arrow Functions:** Function Declarations, Function Expressions, Arrow Functions, Default Parameters, Rest (`...args`).
6. **Arrays & Higher-Order Methods:** `map()`, `filter()`, `reduce()`, `find()`, `slice()`, `splice()`, Mutating vs Non-mutating methods.
7. **Objects & Modern Destructuring:** Key-value pairs, nested object destructuring, property shorthands, spread operator (`...`).
8. **String Methods:** `slice()`, `split()`, `replace()`, `includes()`, `indexOf()`, `trim()`, `toUpperCase()`, `toLowerCase()`.
9. **Template Literals & String Interpolation:** ES6 backtick strings, `${expression}` interpolation, multi-line formatting, tagged templates.
10. **Scope, Hoisting & Closures:** Global/Block/Function scope, Lexical scoping, data encapsulation using Closures.

---

## 🧠 2. Logical Programming Challenges (10 Problems)

1. **String Reversal & Palindrome Checker:** Two-pointer technique and regex character sanitization.
2. **Check Even or Odd Number:** Modulo operator (`% 2 === 0`), bitwise AND (`n & 1`), and batch array classification.
3. **Find Maximum & Minimum in Array:** Single-pass linear scan algorithm with $O(n)$ time complexity.
4. **Factorial & Fibonacci Calculator:** Iterative sequence generators and base case evaluations.
5. **Prime Number Validator & Range Finder:** Optimized divisor search up to $\sqrt{n}$ with prime range generator.
6. **Remove Duplicates from Array:** Comparison between ES6 `Set` and `filter + indexOf`.
7. **Count Vowels and Consonants:** Case-insensitive character parsing and frequency distribution.
8. **Reverse Each Word in a Sentence:** `split(' ')` -> `map(word => reverse)` -> `join(' ')` word-level reversal.
9. **Merge Two Arrays & Remove Duplicates:** Spread operator (`[...a, ...b]`), ES6 `Set` deduplication, and sorted output.
10. **Find All Factors of a Number:** Optimized $O(\sqrt{n})$ divisor finding, sum calculation, prime/perfect number verification.

## ✨ Interactive Features
- ⚡ **Live Test Runner:** For all 20 topics, users can enter custom inputs, click **"Run Code"**, and view the execution logs and output in a simulated browser terminal.
- 📋 **One-Click Code Copy:** Easily copy syntax definitions and full working code solutions to the clipboard.
- 🌓 **Dark / Light Mode Toggle:** Full dark theme support with persistent settings via `localStorage`.
- 🔍 **Live Search & Category Filtering:** Instant fuzzy filtering by title, topic tag, or difficulty level.
- 📈 **Learning Progress Tracker:** Track completed topics with interactive completion checkmarks and an overall progress meter saved to `localStorage`.
- 📱 **Fully Responsive Layout:** Optimized for mobile phones, tablets, and desktop displays.
