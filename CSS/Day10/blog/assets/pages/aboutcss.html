CSS A to Z

1. What is CSS?

CSS (Cascading Style Sheets) is used to style HTML. It controls colors, fonts, spacing, and layout.

2. Adding CSS

You can add CSS in three ways: inline (style="..."), internal (<style> in the head), or external (a separate .css file linked with <link>).

3. Selectors

Selectors choose which HTML to style. Common ones are the element (p), class (.card), and id (#logo).

4. Colors & Backgrounds

Use color for text color and background-color for the background. Values can be a name, hex code, or rgb.

5. Text & Fonts

font-size, font-family, and text-align control how text looks and sits on the page.

6. The Box Model

Every element is a box made of content, padding (space inside), border, and margin (space outside).

7. Width & Height

width and height set the size of an element's content area.

8. Display

The display property controls how an element behaves: block (own line), inline (in the flow of text), or none (hidden).

9. Flexbox

display: flex lines up items in a row or column and makes it easy to space or center them.

10. Positioning

position can be static, relative, absolute, or fixed, used to place elements exactly where you want.

11. Class vs ID

A class (.name) can be reused on many elements. An id (#name) should be used only once per page.

12. Responsive Design

Media queries like @media (max-width: 600px) let your page adjust its style on smaller screens.
