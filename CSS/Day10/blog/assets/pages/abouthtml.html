HTML A to Z

1. What is HTML?

HTML (HyperText Markup Language) is the standard language used to build webpages. It uses tags to tell the browser what each piece of content is, like a heading, a paragraph, or an image.

2. Basic Structure

Every HTML page starts with <!DOCTYPE html>, then an <html> tag that holds a <head> (page info) and a <body> (visible content).

3. Tags & Elements

Most tags come in pairs, an opening tag and a closing tag, like <p>text</p>. Together with its content, this is called an element.

4. Attributes

Attributes give extra info to a tag, written inside the opening tag. Example: <img src="pic.jpg" alt="a cat">.

5. Headings & Paragraphs

Headings go from <h1> (biggest) to <h6> (smallest). Normal text goes inside <p> tags.

6. Links

The <a> tag creates a link. The href attribute tells the browser where it should go.

7. Images

The <img> tag adds an image. It needs a src (image path) and an alt (backup text).

8. Lists

Use <ul> for a bullet list or <ol> for a numbered list. Each item goes inside <li>.

9. Div & Span

<div> groups content in blocks. <span> groups content inline, used for styling small parts of text.

10. Forms

Forms collect user input using <form>, <input>, and <button> tags.

11. Semantic Tags

Tags like <header>, <nav>, <main>, <section>, and <footer> describe the meaning of a section, not just its look.

12. Comments

Write notes in your code that the browser ignores using <!-- comment -->.
